Core Engineering Features

Designed for minimal system intrusion, high frame-rate responsiveness, and background execution.

Passive Media Streaming

Connects to macOS mediaremoted via an isolated daemon. Receives event streams without querying audio inputs or requesting system microphone permissions.

Sub-Second Timeline Interpolation

Compensates for delayed player metadata updates using dynamic timestamp delta interpolation: elapsed + (rate × delta).

120Hz ProMotion Dragging

Direct AppKit window.performDrag(with:) dispatch eliminates SwiftUI gesture feedback loops for zero-lag hardware-accelerated movement.

Click-Through Passthrough

Toggle ignoresMouseEvents instantly with global shortcuts to keep working behind the overlay without moving or closing the window.

LRCLIB Sync & Disk Cache

Queries sanitized song metadata from LRCLIB and serializes parsed timestamps into ~/Library/Caches/Lyrix/. 0 KB network on repeat listens.

Global Keybindings & Customization

Includes an interactive shortcut recorder, configurable lyric glow colors, font scaling presets, and adjustable glass frost opacity.

Metric Measurement Architecture Rationale
CPU Usage 0.0% – 0.2% Event-driven stream with 100ms math timer only during active playback
Memory Footprint (RSS) ~82 MB Native AppKit/SwiftUI framebuffers and in-memory LRC structure
Network Bandwidth ~5 KB / track Single GET request per unique track; 0 KB network on repeat plays
