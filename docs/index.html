ENGINEERING & ARCHITECTURE

Precision engineering. Uncompromising craft.

Lyrix is built exclusively for macOS using native AppKit and SwiftUI subsystems. Every interaction is calculated to feel instant, effortless, and native.

120Hz ProMotion Dragging

Native AppKit Drag Physics with Zero Latency.

By binding directly into AppKit’s native performDrag(with:) runloop, Lyrix tracks your cursor at full 120Hz display refresh rates. No lag, no frame stutter, and zero visual tearing.

120 fps
Sub-Second Interpolation

Millisecond Accuracy.

Compensates for variable system reporting using continuous timestamp algebra: t = elapsed + (rate * Δt) for syllable-precise lyric alignment.

Ghost Mode

Click-Through Freedom.

Toggle ignoresMouseEvents to click, highlight, and type straight through the floating window without ever moving or hiding it.
